# Date of Birth Calculator 🎂

A simple and responsive Date of Birth calculator built with **HTML, CSS, and JavaScript**.

## ✨ Features

- 📅 Enter your date of birth
- 🎂 Calculate your current age
- 📊 Display age information clearly
- 📱 Responsive design
- ⚡ Built with vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
